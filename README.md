# 🗂️ Central de Reservas – ProTec

**Acesse o projeto 👉 [Clicando Aqui](https://github.com/kevinviniciuss/Central-de-Reservas)**

## 📖 Sobre

Sistema de gerenciamento de reservas desenvolvido em **Python**, com o objetivo de aplicar conceitos de Estruturas de Dados, Algoritmos e Programação Modular.

O projeto utiliza **Árvores Binárias de Busca (BST)** e **Árvores AVL** para organizar e consultar registros de reservas, permitindo comparar diferentes estratégias de armazenamento e busca.

## ⚙️ Funcionalidades

📋 Cadastro e gerenciamento de reservas <br>
🔍 Consulta e pesquisa de registros <br>
🌳 Armazenamento e organização utilizando Árvores BST <br>
⚖️ Implementação de Árvores AVL com balanceamento automático <br>
🔄 Percursos em árvores para visualização dos registros <br>
📊 Comparação de operações e desempenho das estruturas <br>
🧩 Organização do código em módulos Python <br>
💾 Carregamento de dados a partir de arquivos JSON <br>
🖥️ Interação com o sistema por meio de menus <br>
↩️ Navegação entre opções do programa <br>

## 🎯 Objetivo

O projeto foi desenvolvido para fins acadêmicos, com foco no estudo e na aplicação prática de:

- Estruturas de Dados (TADs)
- Árvores Binárias de Busca (BST)
- Árvores AVL e algoritmos de balanceamento
- Algoritmos de busca e inserção
- Percursos em árvores
- Análise de eficiência e desempenho
- Manipulação de arquivos JSON
- Programação modular em Python
- Desenvolvimento de sistemas de gerenciamento

## 🚀 Como Executar

**1. Clone o repositório:**

```bash
git clone https://github.com/kevinviniciuss/Central-de-Reservas.git
```

**2. Acesse a pasta do projeto:**

```bash
cd Central-de-Reservas
```

**3. Execute o programa:**

```bash
python main.py
```

> **Observação:** É necessário ter o Python instalado no computador.
